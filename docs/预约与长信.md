# 预约与长信

2026-10-26 更新。入口：主导航「时间表」，或消息对话右上角「预约时间」。个人档案与工作台也提供预约设置入口。

## 使用规则

- 默认只接受留言。开放预约时，需提供未来三天内至少一个空闲时段，最远可设置未来30天；全部按北京时间展示，数据库存储 UTC。
- 开放时间使用周视图：一周七天、每天00:00–24:00，每格15分钟。鼠标可纵向或跨天拖选，再次拖选取消；靠近上下边缘自动滚动，每天支持一键全天开放。今天只开放余下的未来时间，跨周翻页保留草稿。手机可横向查看整周并点选，键盘支持方向键及空格。
- 开放范围与会议时段分开：同一天可连续开放至24小时，不再限制为两小时。发起人从对方开放、且双方均未被站内会议占用的范围中选择具体的开始与结束时间，以15分钟为间隔，默认30分钟。每场预约只占用实际会议时间，余下范围可继续预约。提交即确认，双方时间表和聊天同步出现记录。
- 被预约者临时无法赴约：填写原因，可建议一个其他开放时段。仅原会议占用的那部分时间立即失效并撤回，其余开放时间保留，预约进入「待改期」。建议时段不会预占，发起人确认时再次检查冲突。
- 发起人可以确认建议时间、选择其他可用时间或取消。被预约者通过「无法赴约 / 建议改期」反馈，不能直接替发起人修改会议时间。
- 关闭新预约不会取消已有安排。已有会议以灰色显示并保护；可以调整它前后的空闲时间、合并连续开放范围。涉及会议本身的变动应先从预约记录提出改期。
- 取消、撤回时段均保留历史，不删除关联消息。取消的预约在时间表「历史记录」中查看。
- 会议链接由任一参与者粘贴或后续补充，支持 Zoom、腾讯会议等 HTTPS 地址，只对预约双方可见。默认会议链接只作用于新预约。本站不自动创建第三方会议室，也不读取外部日历。

## 长信与提醒

对话与首次联系均支持最多20,000字符正文、160字符主题。长信折叠阅读；草稿按账号、会话保存在当前标签页，刷新后可恢复。发送过程中继续编辑的新草稿不会被旧消息的成功响应清空。

「已通过其他邮箱另发邮件」是发件人的说明标记，不会实际发送邮件。当前站点不自动发邮箱通知；消息和时间表在页面可见时每20秒更新，回到窗口时也刷新。

## 数据与权限

初始迁移：`prisma/migrations/20261025075752_scheduling/migration.sql`。添加三张表与消息扩展字段，保持原业务记录及旧版本字段兼容。

- `schedule_preferences`：是否开放、说明、默认会议链接、乐观锁版本。
- `availability_slots`：按日存储的开放范围，合并连续网格，软撤回。周视图迁移 `20261025170453_weekly_availability` 将上限放宽为24小时，不更改已有记录。预约继续保留原关联与实际起止时间。
- `bookings`：双方、时间、状态、建议时间、会议链接、乐观锁版本。
- 消息新增主题、邮件说明标记、预约事件与预约关联。

新增表启用 RLS，撤销 `anon` / `authenticated` 表权限；业务请求统一经服务器会话与参与者权限检查。双方用户锁按固定顺序获取，覆盖创建、改期和可用时间编辑，避免同时抢同一时段、同一人跨伙伴重复预约。创建请求具有幂等标识，更新检查版本。预约事件由服务器写入，普通消息不能伪造事件类型。

- 周视图浏览器实测：跨天与反向拖选、16小时拖选及边缘自动滚动、全天96格、跨周草稿与保存、键盘操作；全天范围内创建45分钟会议、同一范围内改期、被预约者撤回半小时并建议当天其他时间、发起人确认。
- 浏览器通过正常表单完成本地注册、完整个人档案及项目发布、开放时间、4,580字符长信、预约、被预约者建议改期、发起人确认、会议链接编辑。
- 草稿刷新恢复及发送期间编辑新草稿通过实际浏览器验证。
- 1440、768、390像素检查时间表、开放时间设置、聊天与改期弹窗，无横向溢出；桌面及手机截图人工复核。
